// 설계 원칙

  • 모든 페이지는 HTML + Markdown 두 버전을 동시 제공

  • /llms.txt — 에이전트용 사이트 전체 인덱스
  • /llms-full.txt — 외부 fetch 없이 전체 콘텐츠 일괄 제공
  • /data.json — 기계 판독용 구조화 데이터
