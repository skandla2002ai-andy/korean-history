FAQ

자주 묻는 질문

사이트 구조와 콘텐츠 방침에 대한 Q&A.

이 사이트의 콘텐츠를 사용해도 되나요?

콘텐츠는 CC BY 4.0 라이선스입니다. 출처(사이트명 + 원문 링크)를 밝히면 상업적 사용을 포함해 자유롭게 사용할 수 있습니다.

사실 본문과 편집자 해석은 어떻게 구분하나요?

글의 type 필드로 구분합니다.

article — 검증된 사료·출처 기반의 사실 본문. 녹색 배지로 표시됩니다.
commentary — 편집자의 해석·의견. 황색 배지와 상단 경고 배너가 표시됩니다.

두 유형은 항상 명확히 구분되며 서로 링크하되 내용이 섞이지 않습니다.

AI 에이전트는 어떻게 이 사이트를 읽나요?

모든 페이지는 HTML과 Markdown 두 버전을 함께 제공합니다. URL 끝에 .md를 붙이면 Markdown 원본을 받을 수 있습니다.

# 사이트 전체 인덱스
curl https://skandla2002ai-andy.github.io/korean-history/llms.txt

# 전체 콘텐츠 통합본 (fetch 1회)
curl https://skandla2002ai-andy.github.io/korean-history/llms-full.txt

# 구조화 데이터
curl https://skandla2002ai-andy.github.io/korean-history/data.json

# 임의 페이지 Markdown 버전
curl https://skandla2002ai-andy.github.io/korean-history/articles/jangbogo.md
출처 사료는 어디서 확인하나요?

각 article 하단의 핵심 사실 섹션에 주요 사료를 명시합니다. 주로 『삼국사기』, 『삼국유사』, 『고려사』, 『조선왕조실록』 등 1차 사료와 해당 분야 연구 성과를 참조합니다.

댓글이나 피드백은 어떻게 남기나요?

현재 댓글 기능은 없습니다. GitHub 저장소 Issues를 통해 의견을 남겨주세요.

새 글은 얼마나 자주 올라오나요?

비정기적으로 업데이트됩니다. 최신 변경 이력은 changelog.md에서 확인할 수 있습니다.
